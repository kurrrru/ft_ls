- libcの任意の関数を使用可能である
- lsを再実装する。`-l`、`-R`、`-a`、`-r`、`-t`のオプションに対応する

### 処理の流れ
1. オプションの処理
2. 取得するファイルを全て取得
3. 必要に応じて属性を取得
4. フォーマットして出力

ただし、途中にソートが入る。
-Rについては、深さ優先探索になっている

オプションは後勝ちになりそう
MacとLinuxでバージョンが違うため、校舎環境を確認した方がいい

ソートは、属性情報に基づくこともある(`-t`は最終編集時刻に基づいてソートするなど)ため、ソートより先に属性取得を行う必要がある

収集 → 属性取得 → ソート → 出力 → 再帰、の順番でやるのが良さそう

まずは、取得する属性を決め、一個のcontentを表す構造体を決めるのが良さそう
